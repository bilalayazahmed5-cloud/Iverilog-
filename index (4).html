Start with the building blocks
Verilog, one concept at a time
Get oriented with the pieces you’ll see in nearly every small design.

        

          
01 · Modules and ports
A module describes a hardware block. Its ports are the signals that connect it to the outside.
module block(input wire a, output wire y);

          
02 · Wires and registers
wire models a connected signal. In Verilog, reg is a procedural variable; it does not by itself guarantee a physical register.
wire ready; reg [3:0] count;

          
03 · Continuous assignments
Use assign for a continuously driven net. The right-hand expression updates as its inputs change.
assign y = (a & b) | c;

          
04 · Always blocks
Combinational logic usually uses always @* and assigns every output on every path.
always @* begin
  y = a ^ b;
end

          
05 · Clocked logic
Use a clock edge in the sensitivity list for sequential logic. Nonblocking assignment models state updates.
always @(posedge clk)
  q <= d;

          
06 · Testbenches
A testbench has no physical ports. It drives inputs, observes outputs, and can end a simulation with $finish.
initial begin
  a = 0; #10 a = 1;
  $finish;
end

        

        

          
SemicolonsEnd declarations, assignments, and procedural statements with ;.

          
Blocking = vs. nonblocking <=Commonly use = in combinational blocks and <= in clocked blocks.

          
Compile vs. simulateiverilog compiles; vvp runs a compiled simulation image.
